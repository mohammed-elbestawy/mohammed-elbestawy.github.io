About

I'm a Computer & Information Sciences student focused on cloud security — currently deepening my AWS security skills through Egypt's DEPI program: VPC architecture, IAM least privilege, and logging & monitoring with CloudTrail and GuardDuty. My approach pairs a developer's understanding of how systems are built — C#, Python, C++ — with an attacker's mindset for finding where they break, which is exactly the perspective cloud security work needs.
